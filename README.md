# 📊StatX
Простой и быстрый telegram-бот для получения статистики игроков с платформы Faceit в игре Counter Strike 2.. Проект реализован на Python и использует LLM для интеллектуального анализа и выборки данных


## Стек технологий
- python 3.12
- telebot - telegram bot API для связи с пользователем
- requests - запрос к API Faceit и Open Router
- matplotlib.pyplot - наглядное сравнение статистик игроков


## 🚀Установка и запуск 

**Вариант 1: из исходного кода**
```
1. pip install -r requirements.txt
2. python main.py # самостоятельное поднятие бота
```

**Вариант 2: готовый бот** (способ временно не работает)
Найдите бота `@statxbot` в Telegram и начните использование без необходимости установки



## Архитектура и структура кода

Код проекта структурирован по модальному принципу и разделяет логику обработки запросов и общение с пользователем:
- `main.py` - точка входа, запуск бот
- `/handlers` - обработчики текстовых команд и запросов пользователей
- `/callback` - логика обработки нажатий пользователя на inline-кнопки
- `/modules` - взаимодействие с API Faceit, интеграция с LLM
- `/translations` - файлы с поддержкой разных языков для интерфейса
- `/data` и `/fonts` - хранение данных пользователей (которые зарегистрировались) и шрифтов



## Функционал

- существует несколько режимов работы бота:
	- `/info` - вывод статистики игрока
	- `/compaer` - сравнение игровых показателей нескольких пользователей
- из запроса пользователя нейросеть извлекает:
	- никнеймы игроков
	- тип метрики (какие показатели между игроками сравнивать)
	- опционально - название карты, статистику между игроками на которой нужно сравнить
- при сравнении игроков бот присылает график с наглядным сравнением статистик
